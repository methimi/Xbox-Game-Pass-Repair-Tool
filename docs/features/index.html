Product overview

Diagnostics that explain the Windows gaming stack

The tool checks connected Xbox, Microsoft Store, Windows, network, storage, security, and gaming-runtime layers before suggesting a repair.

Independent software. Not affiliated with or endorsed by Microsoft or Xbox.
Scan

Broad diagnostic coverage

Checks app packages, Gaming Services, Store infrastructure, services, time, network, storage, GPU, DirectX, anti-cheat context, controllers, and system evidence.

Evidence

Correlated findings

Related signals are evaluated together so one weak symptom is less likely to be shown as a confirmed root cause.

Repair

User-approved actions

The scan itself is read-only. Suitable repairs are listed separately and wait for explicit confirmation.

Verify

Post-repair checks

Relevant checks run again when possible. Outcomes are reported as successful, partial, pending, or failed.

Recover

Repair history and undo

The latest repair session is recorded. Fully reversible settings can be restored; partial or irreversible actions are identified clearly.

Explain

Detailed HTML report

Each completed scan produces a technical report with findings and system context for later analysis.

What the scan covers

WindowsUpdate, BITS, time, files, policies
GamingGPU, DirectX, runtimes, anti-cheat

Result language

A successful check means the inspected area appears healthy. An issue requires reliable evidence. Informational findings provide useful context without declaring failure. Uncertain results stay separate when access, policy, Windows version, or missing evidence prevents a firm conclusion.

What it does not promise

The tool cannot repair Microsoft account, subscription, payment, age restriction, remote service outage, organization policy, or every game-specific problem. A completed repair also cannot guarantee that every title will launch; it verifies only the layers it can inspect.

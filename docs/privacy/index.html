Privacy and diagnostic data sharing

This version sends scan notifications and the completed HTML report to the developer through Telegram. Review the scope before using the application.

No Microsoft connection. Data is sent to the independent developer, not to Microsoft or Xbox.

What may be sent

  • A randomly generated support ID and scan ID.
  • The optional error code entered before the scan, or a notice that no code was entered.
  • Scan findings and the completed HTML report.
  • Windows version, device model, processor, memory, graphics card, and driver information.
  • General disk capacity, network-adapter, security-feature, and Xbox-package information.
  • Resolved or not-resolved feedback and the user's written problem description when submitted.

What the inventory intentionally excludes

  • Personal file contents
  • Passwords and browser history
  • Hardware serial numbers
  • IP addresses and MAC addresses
The report is still detailed. Even without passwords or serial numbers, Windows, hardware, security, package, and diagnostic information can describe a device closely. Do not run the tool unless you accept this transfer.

Information stored on the device

The application keeps the latest repair-history session and associated feedback locally so supported actions can be reviewed or undone. The HTML scan report is overwritten rather than accumulated as separate files.

Telegram delivery

Delivery depends on internet access and Telegram availability. The current implementation sends to a developer-controlled chat. It is not an anonymous public analytics service and should not be treated as one.

Your choices

If you do not accept diagnostic-data sharing, do not start a scan in this version. Remove personal information from any free-text feedback before submitting it.

Xbox games not downloading

Diagnose downloads that remain queued, stop at a percentage, restart repeatedly, or fail in Xbox app or Microsoft Store.

Paused is not broken. A user-paused Store download should not be treated as a failed queue.

Symptoms

  • A game stays queued or shows no progress.
  • Download speed falls to zero and never recovers.
  • An update restarts or fails with a Store/Xbox code.
  • The selected game drive is unavailable.

Likely causes

Typical layers include Store cache, BITS, Windows Update, Delivery Optimization policy, Store queue state, insufficient space, game-drive registration, folder permissions, AppX package health, Gaming Services, account tokens, metered network, DNS, proxy, or Microsoft endpoint access.

Safe manual checks

  1. Confirm the download is not manually paused.
  2. Check free space on both the system and selected game drive.
  3. Install Windows and Microsoft Store updates.
  4. Confirm the same account is signed into Xbox app and Microsoft Store.
  5. Disable VPN temporarily only if endpoint access fails, then test again.

What the repair tool checks

The scanner checks Store download services and queue evidence, BITS, Windows Update, Delivery Optimization, AppX health, Gaming Services, disk space, game drives, folder permissions, account/session consistency, proxy layers, DNS, TLS, endpoints, and metered-network context.

What can be repaired automatically

  • Clear Store cache and DNS cache.
  • Start suitable BITS, Update, Store, and Xbox services.
  • Reset supported proxy layers with approval.
  • Refresh AppX or Gaming Services registration when evidence supports it.
  • Open Store installation flows for missing components.

What cannot be repaired automatically

The tool will not unpause a deliberate queue, buy storage, repair a failing disk, bypass policy, change subscription rights, resolve a Microsoft outage, or reinstall a large game without user action.

Risks and undo support

Cache cleanup is low impact. Proxy reset can remove user proxy configuration, so captured layers are reported separately. App reset, package registration, and Gaming Services reinstall are higher impact and may sign the user out or require restart.

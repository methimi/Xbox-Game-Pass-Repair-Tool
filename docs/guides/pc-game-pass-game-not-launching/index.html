Launch diagnostics

PC Game Pass game not launching

Use this guide when Play does nothing, the title closes immediately, or a game stops launching after an update.

Scope: The tool checks shared Windows gaming layers, not every game file or publisher-specific launcher.

Symptoms

  • The Play button returns to its normal state without opening the game.
  • A splash screen appears and closes.
  • Only one game fails while Xbox app works.
  • Launch fails after a driver, runtime, game, or Windows update.

Likely causes

Shared causes include license/token state, Gaming Services, disconnected game storage, package permissions, DirectX or runtime damage, GPU resets, shader cache, Defender interference, anti-cheat integrity, Secure Boot context, pagefile configuration, system files, or a game-specific defect.

Safe manual checks

  1. Check Xbox service status and restart Windows.
  2. Update the game, Xbox app, Store, Windows, and GPU driver.
  3. Verify or repair the game from its supported app menu when available.
  4. Confirm the installation drive is online and has free space.
  5. Test another Game Pass title to separate shared infrastructure from one-game failure.

What the repair tool checks

The scan covers launch evidence, installed game packages, Gaming Services, Store licensing, account tokens, game drive and permissions, GPU driver and stability events, DirectX/WDDM, runtime inventory, shader cache, Defender signals, anti-cheat infrastructure and events, Secure Boot/VBS context, pagefile, WHEA, and recent event correlation.

What can be repaired automatically

  • Repair suitable shared services and package registrations.
  • Clear DirectX shader cache within safe limits.
  • Refresh Store/Xbox cache and DNS.
  • Repair Gaming Services after approval.
  • Run DISM/SFC when system-file evidence supports it.

What cannot be repaired automatically

The tool cannot patch a specific game's files, update every third-party anti-cheat, bypass subscription or family rules, fix GPU hardware, guarantee driver compatibility, or resolve publisher and Microsoft service outages.

Risks and undo support

Shader-cache removal is low impact but may cause temporary shader recompilation. Package and Gaming Services work is higher impact. DISM/SFC changes protected Windows files and may require restart. Game reinstall remains manual.

Separate shared failure from one-game failure

Run the scan and compare Xbox, runtime, graphics, security, and storage evidence.

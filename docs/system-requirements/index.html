Compatibility

System requirements and supported environments

The tool is designed for current Windows 10 and Windows 11 PCs that use the Xbox app, Microsoft Store, Gaming Services, or PC Game Pass.

Windows only. macOS, Linux, Xbox consoles, and mobile devices are not supported.

Minimum requirements

Operating systemWindows 10 22H2 or Windows 11
Interface runtimeMicrosoft Edge WebView2 Runtime
ConnectivityInternet access
PermissionAdministrator for some checks and repairs

Windows 10 considerations

Windows 10 22H2 is supported, but some higher-impact package repairs are restricted for safety. Windows 10 LTSC may intentionally lack Microsoft Store components; the scanner should treat that context differently from a damaged consumer installation.

Organization-managed computers

WSUS, managed proxy, security policy, Store restrictions, and disabled services may be intentional. Do not override organization policy. Contact the administrator when the scan identifies a managed environment.

Useful preparation

  • Install pending Windows and Microsoft Store updates.
  • Keep enough free space for game and package operations.
  • Connect external game drives before scanning.
  • Close active games, launchers, and installers.
  • Save work before any repair that may recommend a restart.

Tested scenario matrix

The project includes Windows 10/11 scenarios for healthy systems, disabled Gaming Services, missing Xbox packages, time/TLS problems, VPN use, managed proxy, external drives, GPU evidence, anti-cheat context, and large shader caches. A documented matrix is not the same as certification on every PC configuration.

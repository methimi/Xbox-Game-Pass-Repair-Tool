Install and start

  1. Download the installer from the link above.
  2. Open Xbox-Game-Pass-Repair-Tool-Setup.exe.
  3. Follow the setup steps and launch the application from its shortcut.
  4. Approve administrator access only when a repair requires it.
  5. Read the diagnostic-data notice, then start the scan.
Use the official project release. Antivirus software may inspect a newly downloaded executable; download the installer only from this GitHub repository.

Before you run it

  • Save open work and close games.
  • Make sure Windows is supported and WebView2 Runtime is installed.
  • Understand that a completed scan report is sent to the developer through Telegram in this version.
  • Create a Windows restore point before approving high-impact repairs if possible.

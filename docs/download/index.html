Install and start

  1. Download the MSI package from the link above.
  2. Open Xbox-Game-Pass-Repair-Tool.msi.
  3. Follow the Windows Installer steps and launch the application from its desktop or Start menu shortcut.
  4. Approve administrator access only when an in-app repair requires it.
  5. Read the diagnostic-data notice, then start the scan.
Use the official project release. Antivirus software may inspect a newly downloaded installer package; download the MSI only from this GitHub repository.

Before you run it

  • Save open work and close games.
  • Make sure Windows is supported and WebView2 Runtime is installed.
  • Understand that a completed scan report is sent to the developer through Telegram in this version.
  • Create a Windows restore point before approving high-impact repairs if possible.

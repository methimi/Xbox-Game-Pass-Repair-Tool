Install and start

  1. Download the ZIP package from the link above.
  2. Extract the entire archive to a normal folder. Do not run the application from inside the ZIP.
  3. Keep XboxGamePassRepairTool.exe beside the ApplicationFiles folder.
  4. Double-click the executable and approve administrator access when requested.
  5. Read the diagnostic-data notice, then start the scan.
Do not move only the EXE. The ApplicationFiles folder contains required resources. Antivirus software may also inspect a newly downloaded executable; use the GitHub repository and Releases page as the source.

Before you run it

  • Save open work and close games.
  • Make sure Windows is supported and WebView2 Runtime is installed.
  • Understand that a completed scan report is sent to the developer through Telegram in this version.
  • Create a Windows restore point before approving high-impact repairs if possible.

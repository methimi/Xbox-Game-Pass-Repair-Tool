Safety and transparency

Know what the tool can—and cannot—do.

Automatic repair is reserved for suitable actions. Account, subscription, payment, age restriction, Microsoft service outage, and organization policy issues may still need manual action.

  • ✓ Scanning does not change system settings
  • ✓ Repairs require explicit approval
  • ✓ High-impact actions are identified separately
  • ✓ Restarts are never forced without permission
Important

Diagnostic data sharing

This version automatically sends a Telegram notification to the developer when a scan starts and finishes. The completed report can include detailed technical system information, scan results, an optional error code, and user feedback.

It does not report personal file contents, passwords, browser history, hardware serial numbers, IP addresses, or MAC addresses.

Good to know

Frequently asked questions

Is this an official Microsoft or Xbox tool?+

No. This is an independent third-party project. It is not developed, published, supported, or endorsed by Microsoft and has no official or commercial connection with Microsoft, Xbox, or Game Pass.

Does a scan change anything on my computer?+

No. The full scan only reads the current state. Actions that can make changes appear separately and require your approval before they begin.

Why does the app request administrator access?+

Some Windows services, system logs, packages, and repair commands require administrator access to be checked or changed correctly.

Does “successful” guarantee that my game will launch?+

No single repair tool can guarantee that. “Successful” means the requested action completed and was verified where possible. Account, Store, game-specific, or remote service problems can still remain.

What do I need to run it?+

Windows 10 22H2 or Windows 11, an internet connection, Microsoft Edge WebView2 Runtime, and administrator permission for some checks and repairs.

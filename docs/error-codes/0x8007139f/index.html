Gaming Services state

Xbox error 0x8007139F

A PC Game Pass install or launch can fail when Gaming Services exists but cannot enter the state required by Xbox app.

Scan Gaming Services
Related, not identical: Microsoft documented this code beside 0x80073D26, but current failures can come from different package, service, or update conditions.

What the code can indicate

The Gaming Services package may be incomplete, a service may be unavailable, Store delivery may be stalled, or Windows may be waiting for an update or restart to finish.

What the tool checks

  • Both Gaming Services packages and services, including executable paths and recent control-manager errors.
  • AppX package state, Microsoft Store dependencies, and deployment events.
  • Windows version compatibility, updates, BITS, install service, storage, and reboot signals.
  • Cross-checks that distinguish a real service fault from normal trigger-start behavior.

Repair guidance from evidence

The result page recommends only the repairs supported by the findings, marks actions that need a restart, and performs post-repair validation instead of returning success merely because a command ran.

Find the failing layer

Enter 0x8007139F when prompted and let the tool correlate the package, service, and Windows evidence.

What the tool cannot prove

A local scan cannot confirm a remote Xbox outage, entitlement decision, or organization policy controlled outside the PC.

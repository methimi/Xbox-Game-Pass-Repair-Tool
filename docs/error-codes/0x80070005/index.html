Error 0x80070005: Access Denied

This code can appear during Xbox app, Microsoft Store, Gaming Services, or game installation and launch operations.

Do not take ownership of protected folders blindly. Access Denied can come from packages, services, policy, security software, or storage.

Symptoms

  • Installation or launch stops with 0x80070005.
  • A package cannot register or access its expected location.
  • The issue affects Xbox app, Gaming Services, or a game.

Likely causes

Possible causes include package permissions, game-folder access, AppX registration, Gaming Services state, account/session mismatch, Defender Controlled Folder Access, organization policy, storage problems, or an operation that genuinely needs elevation.

Safe manual checks

  1. Restart Windows and retry from the normal Xbox app interface.
  2. Confirm the game drive is connected and writable.
  3. Check Windows Security protection history for a relevant block.
  4. Update Xbox app, Store, Gaming Services, and Windows.
  5. Avoid recursively changing ownership on WindowsApps or protected package folders.

What the repair tool checks

Administrator state, AppX package health, game-folder permissions, user profile, Gaming Services, Defender interference signals, service state, storage, events, and managed-policy context.

Automatic repair options

  • Refresh supported package registrations.
  • Repair Gaming Services after approval.
  • Clear Store cache and start suitable services.
  • Run system-file repair when evidence supports it.

Manual or external actions

Organization policy, security-product decisions, damaged storage, account rights, and protected-folder ownership changes require careful manual or administrator action.

Risks and undo support

App reset and package registration are higher impact. Gaming Services reinstall can interrupt game access. The tool deliberately avoids destructive ownership resets on protected game-storage records; package actions are not fully reversible.

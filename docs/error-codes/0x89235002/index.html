Account token

Xbox app error 0x89235002

The sign-in flow may fail when Windows cannot refresh or use the identity token required by Xbox app and Microsoft services.

Scan account dependencies
Privacy-aware diagnosis: The tool checks local service and configuration evidence; it does not need your Microsoft account password.

What can disrupt the token flow

Account services, Store/Xbox identity mismatch, time drift, TLS validation, a proxy or VPN, blocked endpoints, damaged app packages, or a remote identity incident can produce similar symptoms.

What the scan covers

  • Web Account Manager and Microsoft account service readiness.
  • Xbox authentication, license, Store, and Gaming Services dependencies.
  • Time, time zone, secure transport, DNS, four proxy layers, and endpoint access.
  • Recent event evidence and signs that the issue is remote rather than local.

Useful, bounded results

The report may recommend a supported local repair, request a restart, or clearly say that account verification is still required. Uncertain results do not inflate the problem count.

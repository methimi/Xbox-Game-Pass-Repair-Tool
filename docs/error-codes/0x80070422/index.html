Disabled service

Xbox and Store error 0x80070422

This code commonly appears when a service needed by Windows Update or Store delivery is disabled and Xbox app cannot complete an install or update.

Scan Windows services
State is not enough: A service that is stopped while idle can be normal; Disabled configuration, dependency failure, and event evidence are stronger signals.

What the tool verifies

  • Windows Update, BITS, Delivery Optimization, Store Install Service, and relevant dependencies.
  • Startup configuration, trigger behavior, executable path, policy, and recent service-control errors.
  • Windows update state, pending restart, Store package health, and component-store evidence.
  • Post-repair service and update checks so a command exit code is not mistaken for recovery.

Repair without forcing every service

If evidence supports a safe service correction, the tool records the previous configuration where possible and applies the known Windows-version-aware setting. It does not blindly set every Xbox or Windows service to Automatic.

Possible external causes

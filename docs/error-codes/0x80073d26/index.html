Gaming Services

Xbox error 0x80073D26

This error can appear when installing or starting a PC Game Pass game and Windows redirects you to the Microsoft Store page for Gaming Services.

Download and scan this PC
Microsoft-documented scenario: Microsoft associated this code with Gaming Services on Windows 10. On a current PC, the same code still needs local evidence before repair.

What may be failing

Gaming Services package registration, its background services, Microsoft Store delivery, Windows update readiness, or a pending restart may prevent the install and launch chain from reaching a healthy state.

What the tool checks

  • Gaming Services and Gaming Services Net presence, startup configuration, and recent failures.
  • Xbox app, Microsoft Store, App Installer, and package-registration health.
  • Windows Update, BITS, Store delivery, disk space, pending restart, and policy context.
  • Related AppX and service events so a stopped-on-idle service is not treated as proof of damage.

What happens after the scan

The tool separates confirmed faults from uncertain signals. When a supported repair is available, it explains the impact, records recoverable state where possible, runs the repair, and verifies the affected layer again.

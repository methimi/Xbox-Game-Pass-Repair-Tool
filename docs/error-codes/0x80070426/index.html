Service dependency

Error 0x80070426

This code can appear when the Xbox app starts while one or more required Windows, Store, license, or Xbox services are unavailable.

Service state needs context. Manual and trigger-start services may be stopped while idle without being damaged.

Symptoms

  • Xbox app fails during startup.
  • Sign-in, license, install, or Gaming Services operations do not begin.
  • Windows reports that a required service is not running.

Likely causes

A dependency may be disabled, misconfigured, blocked by policy, failing repeatedly, missing because of package damage, or temporarily stopped according to normal trigger behavior.

Safe manual checks

  1. Restart Windows and retry once.
  2. Install Windows and Store updates.
  3. Check whether the PC is organization-managed.
  4. Do not force every Xbox service to Automatic; expected startup type varies.
  5. Review recent service-control errors, not only the current Stopped label.

What the repair tool checks

Xbox Live service groups, Store download and license services, Gaming Services readiness, BITS, Windows Update, account-token services, configured startup type, trigger behavior, recent service errors, and policy context.

Automatic repair options

  • Apply known-safe startup configuration to the affected service.
  • Start suitable Xbox, Store, BITS, Update, time, and Gaming Services dependencies.
  • Refresh package registration when missing components explain the service failure.
  • Verify service and related evidence after repair.

Manual or external actions

Organization policy, removed Windows components, security-product blocks, remote service incidents, and repeated service crashes requiring deeper event analysis may remain manual.

Risks and undo support

Captured service startup settings are among the more reversible repairs. Package and Gaming Services actions are higher impact and may only be partially reversible. Restart may be required.

Distinguish idle from disabled

Run the scan to evaluate startup type, events, dependencies, and package state together.
